# Documents for @litert/otp

## Exports

This package provides the following entry points:

| Export | Path | Description |
|--------|------|-------------|
| `@litert/otp` | `.` | Main entry — namespace import of all modules |
| `@litert/otp/constants` | `./constants` | Constants and enums (e.g. `EDigest`, `DEFAULT_DIGITS`) |
| `@litert/otp/hotp` | `./hotp` | HOTP (HMAC-based One-Time Password) |
| `@litert/otp/hotp/verbose` | `./hotp/verbose` | HOTP with verbose output |
| `@litert/otp/totp` | `./totp` | TOTP (Time-based One-Time Password) |
| `@litert/otp/totp/verbose` | `./totp/verbose` | TOTP with verbose output |
| `@litert/otp/url` | `./url` | OTP URL encoding and decoding |
